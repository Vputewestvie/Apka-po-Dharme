## Контекст
Проект: Telegram Mini App «Дневник духовной практики», Cloudflare Workers + D1,
`https://dharma-diary.vputewestvie.workers.dev`. Пользователь общается на русском.

## Сделано сегодня
- Расширили библиотеку звуков с 3 до **20 треков** в `apps/mini-app/src/audio-tracks.ts`:
  - 5 длинных тибетских чаш/медитации (2:30–4:30), честные фрагменты без зацикливания
    («сам по себе трек», как просил пользователь; раньше было 3 — этого он счёл мало).
  - 15 звуков природы (костёр, дождь, гроза, море, водопад, ручей, река, птицы,
    кузнечики, ночной лес, пруд, ветер, тихий лес…) по 1:40–3:00.
- Переписали `apps/mini-app/src/components/SoundBathPlayer.tsx` на сетку кнопок с
  тематическими lucide-иконками + кастомная SVG-«поющая чаша» на кнопках питания/вкл-выкл.
  Верхний блок — чаши, нижний — природа. Кнопка включения — без текста, с изображением.

## Источники звука (важно для повторов)
- Чаши: archive.org PD Mark 1.0 — LEONARDO GONZALEZ (longbowls ~108 мин), leo (nepal 60 мин),
  Sean Fitzpatrick (soundbath/low-freq 81 мин).
- Природа: **Mixkit** (Mixkit Free License, прямые превью `assets.mixkit.co/active_storage/sfx/<id>/<id>-preview.mp3`)
  + archive.org `aporee_40321_46050` (костёр 380 с, PD). Долгие ambience/loop из каталога
  нарезаются по профилю громкости; короткие (огонь) склеиваются из нескольких клипов.

## Пайплайн сборки (tmp/*.mjs) — переиспользуемый
- `profile.mjs` — RMS по фреймам; `pick.mjs` — выбор лучших окон (cum-сумма квадратов
  восстанавливает RMS любого отрезка из накопительной RMS astats).

  кольцо `[tail][main]`, моно ДО loudnorm, двухпроходный loudnorm, mp3 64k mono.
